## Note on reproducibility

This file DOCUMENTS the environment but does not allow it to be RESTORED.
For strict reproducibility, initialise `renv` at the project root:

```r
renv::init()      # once
renv::snapshot()  # after every change of packages
```

The resulting `renv.lock` lets a third party restore exactly the same
versions with `renv::restore()`. It should be committed to the repository.
